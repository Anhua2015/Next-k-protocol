# Bitget 多标的网格（wangge）

源码：`vendor/wangge`。只保留 **Bitget** USDT 永续。

## 模型

| 项 | 说明 |
|----|------|
| 交易所 | 仅 Bitget（共享账户） |
| 选币官 | 自维护候选池；按成交额+ATR+趋势打分；**最多 5 个**机器人自动开停 |
| 托管 | 启动后 EMA/ATR 自动调区间/换向（paper/live 同规则） |
| 模式 | `BG_MODE=paper` / `live` |

## 无干预

`BG_SYMBOLS` 建议留空，由选币官维护名册（最多 5）。进程约 20s 首次巡检：空仓时一次可开满高分标的；已有运行中后再开需要连续确认。之后默认每 **2 小时**巡检，**至少持有 6 小时**才可淘汰/替换。

详见 `.env.example`。
