# Next K 网格（Bitget）

源码目录名仍为 `vendor/wangge`（部署路径未改）；产品面统称 **Next K**。只保留 **Bitget** USDT 永续。

## 模型

| 项 | 说明 |
|----|------|
| 交易所 | 仅 Bitget（共享账户） |
| 选币官 | 仅白名单：核心 BTC/ETH/SOL/BNB/XRP/DOGE + 次核心约 15 个大盘；次核心需更高分且偏震荡才开；默认中性，仅极强趋势（≥75%）才做多/做空；最多 5 机 |
| 托管 | 默认中性 50 格 + 30x + 冲出区间平仓；自动调区间；换向门槛更高（约 55%）；强震荡可切回中性 |
| 手续费 | Bitget U 本位：maker 0.02% / taker 0.06%；网格间距按 maker 往返 0.04% 校验 |
| 模式 | `BG_MODE=paper` / `live` |

## 无干预

`BG_SYMBOLS` 建议留空，由选币官在**流动性白名单**内维护名册（最多 5）。进程约 20s 首次巡检：空仓时一次可开满高分标的；已有运行中后再开需要连续确认。之后默认每 **2 小时**巡检，**至少持有 6 小时**才可淘汰/替换。名单外旧仓会累计剔除分。

详见 `.env.example`。
